## 📂 Featured Engineering Projects

### 🎨 [Chrono Canvas](https://chronocanvas.com)
A specialized social platform engineered for digital artists, focusing on the chronological evolution and timeline history of artwork.
* **Tech Used:** Vite, React, Supabase, Tailwind CSS, GSAP Animations
* **Key Features:**
  * Chronological artwork timeline tracking and historic revision rendering.
  * Deeply optimized dark-mode UI customized for visual media display.
  * Real-time image asset delivery and database persistence state synchronization.

### 🍲 [UlamTipid](https://ulamtipid.com)
A smart, budget-conscious full-stack web application designed to help users manage meal planning and calculate optimal recipe costs efficiently.
* **Tech Used:** MongoDB, Express.js, React, Node.js (MERN), Tailwind CSS
* **Key Features:**
  * Dynamic recipe costing calculation engines interacting seamlessly via RESTful API endpoints.
  * Flexible, non-relational document indexing schema built to handle dynamic recipe variations and component arrays.
  * High-performance single-page application layout for seamless state tracking and budget manipulation.

### 🔒 [Env Vault](https://envvault.com)
A security-focused developer utility built for managing, isolating, and securely handling project environment variables.
* **Tech Used:** React, Node.js, Tailwind CSS
* **Key Features:**
  * Clean, interactive data dashboard for organizing sensitive key-value pairs.
  * Localized project configuration profile grouping.
  * High-fidelity, minimal interface built to align seamlessly with developer workflows.
